종합 분석 (Comprehensive) — 출력 데이터 필드 명세

종합 커리어 분석 v3.1 (환각 차단 재설계 + STAR 품질 채점) · career_analysis_comprehensive.py · build_system_prompt_comprehensive() · hallucination_guard.py / star_quality.py 검증 · main() envelope 반환

필수 — LLM이 반드시 채워야 하는 값 선택 — 비어있을 수 있는 값 시스템 — LLM 출력과 무관하게 코드가 계산·강제 주입/덮어쓰기 조건부 — 특정 상태일 때만 값이 채워지고 그 외엔 null NEWv3.1 신규 필드 v2.0v2.0 에서 삭제됨

⚠️ 이 문서는 v2.0 명세서가 아닙니다. v2.0 스펙에 있던 search_query · search_verified · expired_jobs · is_valid 필드는 v3.1 코드에 더 이상 존재하지 않습니다 — 동아리·자격증·공모전은 자기검증(같은 모델이 스스로 verified: true를 매기는 방식) 대신 반증형 이중 검증 + 그라운딩 대조 + HTTP 프로브로 교체되었고, 채용공고는 만료 배열을 따로 두지 않고 애초에 마감 지난 공고를 생성 단계에서 만들지 않습니다. 모든 항목은 실제 소스 코드 (career_analysis_comprehensive.py 1,900행 + hallucination_guard.py 910행 + star_quality.py 400행)를 직접 읽어 검증했습니다.
🧩 공통 반환 형식(envelope) — main()은 아래를 반환합니다. 성공: { "status":"success", "result":{…payload…}, "vector":[…] } · 실패: { "status":"error", "message":"…" }. 아래 02번 이후 필드는 전부 result 안쪽입니다. vector — 임베딩 3072차원 배열(gemini-embedding-001). result 밖 별도 필드. result 안에는 status·vector 를 넣지 않습니다(§3.6 규약, payload = {k:v for k,v in result.items() if k not in ("status","vector")}).
